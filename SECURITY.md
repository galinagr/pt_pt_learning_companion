# Security Policy 🛡️

## Supported versions

This project is currently in active preview. Security fixes are applied to the
latest version on the default branch.

## Reporting a vulnerability

If you discover a security issue, please do not open a public issue.

Instead, share details privately with maintainers and include:

- A clear description of the issue
- Reproduction steps or proof of concept
- Potential impact
- Suggested mitigation (if known)

We will acknowledge reports as quickly as possible and work on remediation.

## Secret handling

- Never commit API keys, tokens, passwords, or credentials.
- Use environment variables for secrets.
- Rotate exposed credentials immediately.
